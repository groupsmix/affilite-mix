# Admin API machine access

The authoritative AI/operator documentation is the
[Automation API integration guide](./automation-api.md). It covers creating
and authenticating a scoped service account, the full-admin bearer-token
difference, machine-denied admin routes, owner approval, rollback, errors, and
read surfaces.

Use this page as a stable legacy link for references that previously pointed
at full-admin bearer-token guidance. Do not give an AI agent a full-admin token
for routine dashboard operations.
