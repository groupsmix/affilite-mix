# Export Control Classification Number (ECCN)

## Self-Classification
**Product:** Affilite-Mix
**ECCN:** 5D992.c (Mass Market Encryption Item)

## Justification
The Affilite-Mix platform utilizes standard, open-source cryptographic libraries for authentication, data-in-transit encryption (TLS/HTTPS), and hashing (bcrypt, SHA-256 via Web Crypto API). 

Per the Bureau of Industry and Security (BIS) Export Administration Regulations (EAR), software that utilizes encryption for standard authentication, password protection, and TLS is eligible for self-classification under 5D992.c as a "mass market" encryption item, provided it does not provide custom cryptographic algorithms or primary cryptanalytic functions.

## CCATS / BIS 740.17(b)(1) Notification
Since the software falls under mass-market self-classification (5D992.c) and is not designed for government end-users, an annual self-classification report to the BIS and the ENC Encryption Request Coordinator may be required if the software is exported in object code format.
