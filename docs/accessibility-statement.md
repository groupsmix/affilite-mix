# Accessibility Statement

> Path: `docs/accessibility-statement.md`  
> OF-14: Required by EN 301 549 / WCAG 2.1 AA for EU/EEA public-sector and
> many commercial websites.

## Scope

This document covers the **affilite-mix** multi-site affiliate platform at
`*.groupsmix.com`.

## Standard Applied

WCAG 2.1 Level AA (ISO/IEC 40500:2012).

## Conformance Status

**Partially conformant** — some content does not fully conform due to
third-party dependencies (sandboxed ad slots, CMP) noted below.

## Known Issues

| Issue | Impact | Target fix |
|-------|--------|-----------|
| Third-party ad iframes | Level A — no accessible name | Ad partner review |
| Cookie consent dynamic region | Level AA — live region announcements | CMP upgrade |
| Price history chart table alternative | Level A — no data table fallback | Q3 2026 |
