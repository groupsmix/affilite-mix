## Substantive web-translated findings

### F-A119 — URL handling, redirects, auth-in-URL — PASS

- `lib/safe-redirect.ts` allow-lists relative + same-origin + explicit
  `allowedOrigins`; rejects `javascript:`, `data:`, protocol-relative
  `//evil.com`, and non-`http(s)` schemes.
- Auth tokens in email-link UX (newsletter confirm/unsubscribe, password
  reset) are single-use UUIDs validated server-side. Session JWTs are
  cookie-based, never query-string.
- CSRF protection enforced in `middleware.ts` for state-changing
  methods.

### F-A120 — Bundle / source for hardcoded secrets, debug flags — PASS

- No production secrets hardcoded. `DEV_ONLY_*` constants throw at
  runtime in production (`lib/jwt-secret.ts`, `lib/internal-auth.ts`).
- No `__DEV__` / `enableDebug` flags shipped to prod.
- `getCspExternalHosts()` (`lib/csp.ts`) derives Supabase + R2 origins
  from env vars only; no wildcard.
- Gitleaks + CodeQL run on every PR.

### F-A124 — CSP / mixed content / dangerouslySetInnerHTML — PASS

- CSP: `script-src 'self' 'nonce-…' 'strict-dynamic'`,
  `style-src 'self' 'nonce-…'`, `object-src 'none'`,
  `frame-ancestors 'none'`, `base-uri 'self'`, `form-action 'self'`.
- All `dangerouslySetInnerHTML` call-sites sanitise via
  `sanitizeHtml(...)` or `safeJsonLdString(...)`.
- Only `file://` reference is in `__tests__/ssrf-guard.test.ts`
  asserting rejection.

### F-A125 — SDK supply chain — PASS (minor)

- `npm audit --omit=dev` → 0 vulnerabilities at audited commit.
- No data-collection SDKs (no Segment / Amplitude / FB-SDK / Branch /
  Adjust).
- Sentry telemetry is present and disclosed in the cookie-consent
  banner.
- Apple Privacy Manifest is N/A — no iOS bundle.

### F-A129 — Access control (web RBAC) — PASS

- Two-tier role model: `admin` and `super_admin` (`lib/admin-guard.ts`).
- `withAuthz(feature, action, handler)` and `withAuthzDynamic(...)`
  wrap every admin route.
- Service-role Supabase client gated by
  `lib/security/service-role-allowlist.ts`.
- 185 Supabase migrations, RLS enabled, tenant-isolation tests in
  `__tests__/tenant-isolation.test.ts`.
